OAuth setup secret

Stops a stranger who finds your public tunnel URL from authorizing the bot against their own OneDrive. It gates /oauth/start as a query param, and reaches /oauth/callback inside the OAuth state parameter, which Microsoft returns untouched. Generated automatically on first boot -- you don't need to set it yourself.

Regenerating no longer changes the redirect URI, so the Entra app registration does not need updating when you do. It only invalidates a sign-in that is already in flight; just start again from the button below.
